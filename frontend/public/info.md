# 자기소개서

비전공자로서 개발자의 길을 선택한 뒤, 체계적인 학습을 위해 교육기관(대덕인재개발원 25년 14기)에서 백엔드·React·전자정부 프레임워크 기반의 풀스택 과정을 수강하며 역량을 키우고 있는 신입 개발자입니다.

비전공이라는 한계를 극복하기 위해, 단순히 기능을 따라 만드는 데서 그치지 않고 인터넷 강의와 학원 교육자료를 통해 '기본 개념부터 이해하는' 학습 방식을 가장 중요하게 생각합니다. 코드와 실행 결과를 직접 비교하며, 특정 명령어·함수·키워드가 어디서 실행되고 어떤 로직 위에 있는지 분석하는 실습과 복습을 병행하고 있습니다. 오류가 발생하면 로그와 에러 메시지를 근거로 원인을 추적하고, 자료를 참고해 스스로 해결하는 습관을 기르고 있습니다. 또한 자율 시간을 활용해 개인 프로젝트를 만들며, 즐기면서 학습하고 역량을 강화하고 있습니다.

## 리더십과 협업

프로젝트는 결국 팀워크이며, 팀의 분위기에 따라 결과와 학습 환경이 달라진다고 판단해 학원에서 한 조의 팀장(PL)을 자원했습니다. 대학 시절 1학년 과대표, 2학년 학회장, 그리고 자영업 경험을 바탕으로 리더십에 자신이 있었기에, 팀의 분위기를 어떻게 이끌지와 전공자의 역량을 어떻게 효율적으로 분산할지를 고민하며 팀을 리드했고, 중간 프로젝트를 성공적으로 마쳤습니다. 이 과정에서 게시판의 백엔드·프론트엔드 영역을 직접 담당했으며, 리더십과 협업 능력이 개발에서 매우 중요한 역량이라는 것을 체감했습니다.

## 프로젝트 기술 리뷰

실무 경험을 대신할 결과물로, 직접 개발한 플레이그라운드(개인 기술 블로그)와 팀 프로젝트를 통해 전체 서비스 구조를 이해하려 노력했습니다.

### 개인 기술 블로그 (Spring Boot + React)

프론트엔드(React/TypeScript)와 백엔드(Spring Boot)를 REST API로 연결한 풀스택 개인 블로그입니다. GitHub OAuth와 JWT로 인증 구조를 직접 설계하고, 게시글은 Markdown으로 작성하면 콘텐츠 저장소에 자동으로 커밋되도록 작성·수정·삭제(CRUD)를 구현했습니다. 댓글·대댓글, 방명록, 방문자 통계 기능과 Caffeine 캐시를 적용했고, Oracle Cloud 서버에 Nginx·도메인(DuckDNS)·SSL(Let's Encrypt)로 직접 배포한 뒤 GitHub Actions로 빌드·배포(CI/CD)까지 자동화하며 '실제로 운영되는 서비스'의 전 과정을 경험했습니다.

### Cinema Talk — 영화 커뮤니티 (5인 팀)

TMDB API를 연동해 영화 정보를 제공하고, 투표·토론으로 소통하는 커뮤니티 웹 서비스입니다. Java·Servlet·JSP·MyBatis·Oracle DB 기반의 5인 팀 프로젝트에서 게시판 도메인을 담당했습니다. 게시글 작성·조회·수정·삭제(CRUD)와 목록 조회, 상태·조건별 필터링을 구현했고, MyBatis 매퍼로 SQL을 관리하며 jQuery·AJAX로 비동기 처리를 적용했습니다. 특히 상태 필터 조회 과정에서 'DB 조회 성공이 곧 화면 반영 성공은 아니다'라는 점을 디버깅으로 체감하며, Controller에서 View로 이어지는 데이터 흐름을 순서대로 추적하는 습관을 길렀습니다.

> 위 두 프로젝트의 상세 기능과 트러블슈팅 기록은 개인 블로그와 GitHub에 자료로 정리해 두었습니다.

MVC 패턴, Servlet, JSP는 물론 Spring·Spring Boot 기반의 백엔드와 React를 활용한 프론트엔드를 함께 이해함으로써, 전체 서비스 구조를 파악하고 협업에 강한 개발자로 성장하고자 합니다.

## 입사 후 포부

비록 실무 경험은 없지만, 꾸준함과 성실함, 그리고 빠르게 배우려는 태도만큼은 자신 있습니다. 탄탄한 기초를 바탕으로 지속적으로 성장하며, 당사와 함께 발전하는 백엔드·풀스택 개발자가 되고 싶습니다. 제자리에 머무르는 개발자가 되고 싶지 않습니다. 현재 학습 중인 풀스택을 첫 번째 성장 목표로 삼고, 더 나아가 새로운 언어와 시대의 흐름에 맞는 개발 영역까지 한계를 정해두지 않고 배우고 발휘하는 개발자가 되는 것이 목표입니다. 다양한 방향성을 잡고 역량을 강화해 훌륭한 인재로 거듭나겠습니다.

누구보다 간절한 마음에 글이 길어졌음에도 끝까지 읽어주신 당사에 감사의 말씀을 올리며, 이력서 자기소개를 마치겠습니다. 감사합니다.
